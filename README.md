# PUBG 测距尺 (PUBG Ruler)

DEMO: [https://pubg.eallion.com](https://pubg.eallion.com)

专为《绝地求生》（PUBG: BATTLEGROUNDS）设计的屏幕物理测距尺生成工具。通过浏览器本地矢量计算，为玩家生成 1:1 精确贴合显示屏的实体纸张测距尺。

---

## 核心特性

- **多规格地图适配**：支持 8×8（放大 3 次）、4×4（放大 2 次）及 3×3/2×2（默认视图）网格规格。
- **物理几何引擎**：自动识别标准比例与非标拉伸分辨率（如 1728×1080），自适应生成同心圆或长短半轴同心椭圆。
- **设备物理数据库**：内置主流台式电竞显示器与游戏笔记本面板物理尺寸库，并支持自定义测量录入。
- **高精度矢量输出**：支持 A4、A3、A5、B4、B5 等多纸张规格的微米级矢量 PDF 与 SVG 导出。
- **双向打印公差补偿**：内置物理校准线，支持输入打印机机械拉伸实测值，自动逆向补偿出纸公差。
- **纯前端与数据私有**：零后端依赖，所有计算与配置均在客户端本地完成。

---

## 使用步骤

1. **设置游戏基准**：游戏内设置 `世界地图缩放灵敏度: 10`；
2. **选择屏幕与分辨率**：选择当前显示器/笔记本型号及游戏渲染分辨率；
3. **确认地图规格**：根据对局地图切换规格（8×8 放大 3 次、4×4 放大 2 次）；
4. **生成并打印**：导出 PDF，推荐使用 **110g 硫酸纸** 打印以方便透视屏幕，打印时建议选择【实际大小 / 100% 比例】无缩放打印；
5. **校准与核验**：使用直尺测量纸张左侧标尺，如存在打印机走纸拉伸偏差，可输入实测值一键校准重构。

## 本地运行与部署

本项目为纯静态 Web 应用，无需任何编译构建步骤。

### 本地运行
在项目根目录下启动静态 HTTP 服务即可：

```bash
python3 -m http.server 8080
```
访问 `http://localhost:8080` 即可使用。

### 线上部署
支持一键部署至任何静态托管平台（如 Cloudflare Pages、Vercel、Tencent Cloud EdgeOne Pages）：
- 构建命令（Build Command）：留空
- 输出目录（Output Directory）：根目录（`/` 或 `.`）
